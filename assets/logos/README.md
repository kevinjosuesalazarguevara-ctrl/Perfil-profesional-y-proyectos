# Logos

Marcas de una sola tinta (blanco con transparencia). El portafolio las usa como máscara CSS, así toman el color del texto y cambian a verde al pasar el mouse.

- `accenture.svg`, `anthropic.svg`, `claude.svg`, `intel.svg`: Simple Icons (CC0).
- `teknowledge.png`, `maecre.png`, `intel.png`, `concentrix.png`: convertidos desde los logos oficiales que proporcionó Kevin.

Las marcas pertenecen a sus dueños.
