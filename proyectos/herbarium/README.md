# Comercializadora Herbarium — Transformación digital

**Rol:** Digital Transformation Consultant (proyecto independiente)
**Periodo:** 2026 – Actualidad
**Enfoque:** remodelación, modernización y automatización de procesos de negocio con herramientas Microsoft y Claude (Anthropic).

## Objetivo

Reducir el trabajo manual, ordenar la información del negocio y dar visibilidad a la operación, con una base segura sobre Microsoft 365.

## Enfoque por fases

1. **Diagnóstico (AS-IS):** levantamiento de procesos actuales, tareas manuales, cuellos de botella y fuentes de datos.
2. **Diseño (TO-BE):** procesos objetivo y hoja de ruta priorizada por impacto y esfuerzo.
3. **Base de trabajo:** Microsoft 365, Teams, SharePoint y OneDrive con identidad y seguridad configuradas.
4. **Automatización:** flujos y apps para aprobaciones, notificaciones y captura de datos.
5. **Datos y reportes:** tableros de gestión en Power BI.
6. **IA aplicada:** asistentes y agentes para documentación, análisis y consultas internas.

## Herramientas

| Necesidad | Herramienta |
|---|---|
| Colaboración y documentos | Microsoft 365, Teams, SharePoint, OneDrive |
| Flujos automáticos | Power Automate |
| Apps internas | Power Apps |
| Captura de datos | Microsoft Forms, Microsoft Lists |
| Reportes | Excel (Power Query), Power BI |
| Asistentes y agentes de IA | Microsoft Copilot, Copilot Studio |
| Documentación, análisis y prototipos | Claude (Anthropic) |
| Identidad y seguridad | Microsoft Entra ID (MFA, acceso condicional), Intune, Defender, Purview |
| Gestión comercial (opcional) | Dynamics 365 Business Central, Microsoft Bookings |

## Entregables

- Mapa de procesos AS-IS / TO-BE
- Hoja de ruta de modernización
- Flujos y apps en Power Platform
- Procedimientos operativos (SOPs)
- Tableros en Power BI
- Línea base de seguridad de Microsoft 365
