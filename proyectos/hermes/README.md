# Hermes: automatización y agente de IA

**Contexto:** iniciativa interna en Accenture (Expert Technology Consultant, Microsoft Solutions)
**Periodo:** 2025 – Actualidad

> Trabajo realizado para Accenture: aquí solo se describe. No se publica código, datos ni configuraciones.

## Problema

El seguimiento de reservas y llamadas con clientes dependía de tareas manuales, lo que generaba llamadas vencidas sin aviso y poca visibilidad del estado de cada caso.

## Solución

**Hermes Automation (Power Automate)**
- Cada nueva reserva en Microsoft Bookings crea automáticamente un ticket en Microsoft Lists y una tarea en Planner.
- Un flujo diario detecta llamadas vencidas y envía recordatorios por Outlook y Teams.

**Hermes AI Agent (Copilot Studio)**
- Agentes que responden en lenguaje natural, desde Teams, sobre el estado de tickets, llamadas pendientes y la carga de trabajo del día.

## Resultado

Mejor orden del pipeline, más responsabilidad sobre cada caso y respuestas más rápidas. El agente aumentó la adopción de la automatización.

## Tecnologías

Power Automate · Microsoft Bookings · Microsoft Lists · Planner · Outlook · Microsoft Teams · Copilot Studio
